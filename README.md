# Nauka

Strony do nauki na GitHub Pages: https://wnasilow.github.io/nauka/

- `kpp/` – kurs przed recertyfikacją KPP (postęp w localStorage, eksport/import na stronie kursu)
- `manchester/` – fiszki z zestawu Quizlet „Manchester”, aktualizowane automatycznie z serwera (strona, podcast `feed.xml`, PDF, EPUB)
- `dzis/` – codzienna lista zadań (języki, KPP, kursy, algorytmy, boks) z linkami otwierającymi aplikacje; `jezyki/` przekierowuje tutaj
